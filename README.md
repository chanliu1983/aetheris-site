# Aetheris — Support, Privacy & Marketing

A turn-based mech strategy game of water, power and steel: found a fortress in the desert,
pipe water to it, wire up power, and command a small mech army hex by hex.

**This repository is not the game.** It is the public web presence for Aetheris (圣脉荒原):
the marketing page, the privacy policy, and the place to report problems.

## Reporting a problem

**Open an issue:** <https://github.com/chanliu1983/aetheris-site/issues/new>

Say which version you play (bottom of the main menu), your Mac and macOS version, what you
were doing, and — if you can — attach a save from the moment it happened.
